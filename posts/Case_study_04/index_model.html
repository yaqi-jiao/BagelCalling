Case

Before starting this project and reading the code, i usually treated paths as simple locations and arguments as simple CLI inputs. But in this project, I noticed that args is used as a shared configuration object. Some values come from CLI, some are generated during runtime, and some are later used to build paths, model names, and tracker states.

Samplecode: parapms.py 
def make_output_dir(args, proj_path, script_path, hypertune):
    # Generate output date and time
    output_date_time = datetime.now().strftime("%Y%m%d_%H%M%S")
    print("Program starts at {}".format(
            datetime.strptime(
                output_date_time, "%Y%m%d_%H%M%S"
            ).strftime("%d-%m-%Y %H:%M:%S")
        ))
    if not args.output_date_time:
        args.output_date_time = output_date_time

    # Define paths
    args.proj_path = proj_path
    args.script_path = script_path
    args.input_path = os.path.join(proj_path, "data")

    # Determine folder structure based on hypertuning and epicenter
    tune_folder = "hypertune" if hypertune else ""

    epi = ("precuneus" if "precuneus" in args.epicenter_list
        else "entorhinal" if "entorhinal" in args.epicenter_list
        else "")

    if "null_model" in args.model_name:
        tune_folder = "Null_models"

    # Add connectivity and regional vulnerability to model_name
    if args.SC and args.SC not in args.model_name:
        args.model_name += f"_{args.SC}"

    for var in [
        "spread_var", "synthesis_var", "misfold_var",
        "clearance_nor_var", "clearance_mis_var",]:
        value = getattr(args, var)

        if isinstance(value, str):
            regional_name = f"{var.split('_')[0]}-{value}"

            if regional_name not in args.model_name:
                args.model_name += f"_{regional_name}"

    # Construct output path
    args.output_path = os.path.join(
        proj_path, "results", args.simulated_protein,
        args.protein_type, tune_folder, epi,
        f"{args.model_name}_{args.output_date_time}",
    )

    # Create output directory
    os.makedirs(args.output_path, exist_ok=True)
    print(f"Output directory created at: {args.output_path}")

    return args

def __init__(self, args, param_combinations):
    self.checked_epicenter = (
        args.epicenter_list.split(",")[0]
        if isinstance(args.epicenter_list, str)
        else args.epicenter_list[0]
    )
    self.mean_scatter_times_list = args.mean_scatter_times_list
    self.n_jobs = args.n_jobs
    self.T_total = args.T_total
    self.output_path = args.output_path
    self.param_combinations = param_combinations
    self.null_model = args.null_model_i

    # Initialize storage structures
    self.y = None
    self.r_dict = {
        "simulation": {self.checked_epicenter: {
                "combinations": [], "max_r_each_run": [-1000],
                "max": [], "max_indices": [],
            }},
        "Rmis": {self.checked_epicenter: {
                "combinations": [], "max_r_each_run": [-1000],
                "max": [], "max_indices": [],
            }},}
    self.best_combination = {
        "simulation": {self.checked_epicenter: {}},
        "Rmis": {self.checked_epicenter: {}},
    }
    self.simulated_data = {"simulation": [], "Rmis": []}


def summary(self):
    for result_type in self.simulated_data:
        print("*" * 5, result_type, "*" * 5)
        max_r_list, ind_max_param, pred_best = self.get_best_params(result_type)

        if self.null_model is None:
            best_model_name = (
                f"_p_stay_{self.param_combinations[ind_max_param][0]}"
                f"_trans_rate_{self.param_combinations[ind_max_param][1]}"
                f"_v_{self.param_combinations[ind_max_param][2]}"
            )
            self.print_and_plot_best(
                result_type, pred_best, max_r_list, best_model_name
            )


def save(self):
    start = time.time()

    np.save(os.path.join(self.output_path, "Y_observed.npy"), self.y)

    for result_type in self.simulated_data:
        print("*" * 5, result_type, "*" * 5)

        with gzip.open(
            os.path.join(self.output_path, f"Simulated_data_{result_type}.npy"),
            "wb",) as f:
            np.save(f,
                np.array(self.simulated_data[result_type], dtype=np.float16),)

        # Save performance metrics for the current result type
        with open(os.path.join(self.output_path,
                f"hyperparameters_model_performance_{result_type}.pkl",), "wb",) as f:
            pickle.dump(self.r_dict[result_type], f, protocol=4)

        # Save intermediate outputs for the current result type
        with open(os.path.join(self.output_path,
                f"hyperparameters_model_intermediate_outputs_{result_type}.pkl",),"wb",) as f:
            pickle.dump(self.best_combination[result_type], f, protocol=4)

    end = time.time()
    print(f"saving time: {(end - start) / 60} mins")

Study

1. args as configuration

When i read the code, i can see some important variables, not just from CLI, but also some intermediate arguments, which can be read, are passed as additional parameters to args, making it a storage place for all necessary variables.

args = parse_arguments(hypertune=True)

For example:

  • user input arguments (the way it is)
  • important path information
  • time information (timestamp, script runtime settings)
  • model metadata
  • markers

It can also avoid another problem: If i just use normal variables in the scripts, and does not return it, when I add more functions and want to use the variable, I can’t, because it’s being wrapped and not returned. But making functions return too many variables seems not a good idea also, especially you are trying to maintain a very large project and only want to make script return most plain and useful things.

Passing args among scripts is much more easy and straightforward than passing specific variables, Because you have to pay more attention to details like ‘which variables should I allow this function return? When to update the variables? Do I need this variable in future functions?’

2. Metadata stored in paths

Although relatively simple, but from the code we can see how it puts arguments as conditions, or even parts of the output path.

# Determine folder structure based on hypertuning and epicenter
tune_folder = "hypertune" if hypertune else ""
epi = "precuneus" if "precuneus" in args.epicenter_list else ("entorhinal" if "entorhinal" in args.epicenter_list else "")
if "null_model" in args.model_name: tune_folder = "Null_models"

# Add connectivity and regional vulnerability to model_name
if args.SC and args.SC not in args.model_name: args.model_name += "_" + args.SC
for var in ["spread_var", "synthesis_var", "misfold_var", "clearance_nor_var", "clearance_mis_var"]:
    if isinstance(getattr(args, var), str):
        regional_name = var.split("_")[0] + "-" + getattr(args, var)
        if regional_name not in args.model_name:
            args.model_name += "_" + regional_name

args.output_path = os.path.join(proj_path, "results", args.simulated_protein, args.protein_type, tune_folder, epi, args.model_name + "_" + args.output_date_time)

In this section:

  1. args.epicenter_list and args.model_name is used to help determine the name of tune_foler
  2. args.SC is used to add SC details to the model names
  3. it sets a condition to get var in args, and create regional name for args.model_name
  4. the args.model_name is then being used to construct output path

3. Metadata stored in objects

The project code is a mixture architecture of OOP and OPP. The TuningResultTracker is a stateful object, (Although the project is mostly procedural, the tracker introduces a class because it needs to maintain evolving state across many iterations. i’m not very familar with OOP yet, so i can’t dig very deep into this topic in this case study)

Anyways, for other OPP scripts, they just need to process received args, but for TuningResultTracker, which has an individual inner system, the variables may keep changing, making global args harder to uodate for every condition, also not all global arguements are needed in this class, so what the code did is:

def __init__(self, args, param_combinations):
        self.checked_epicenter = [x for x in args.epicenter_list.split(",")][0] if isinstance(args.epicenter_list, str) else args.epicenter_list[0]
        self.mean_scatter_times_list = args.mean_scatter_times_list
        self.n_jobs = args.n_jobs
        self.T_total = args.T_total
        self.output_path = args.output_path
        self.param_combinations = param_combinations
        self.null_model = args.null_model_i

        # Initialize storage structures
        self.y = None
        self.r_dict = {"simulation":{self.checked_epicenter: {"combinations":[],"max_r_each_run":[-1000], "max":[], 'max_indices':[]}},
                       "Rmis":{self.checked_epicenter: {"combinations":[],"max_r_each_run":[-1000], "max":[], 'max_indices':[]}}}
        self.best_combination = {"simulation":{self.checked_epicenter:{}}, "Rmis":{self.checked_epicenter:{}}}
        self.simulated_data = {"simulation":[], "Rmis":[]}

It’s worth mentioning that, arguments are not simply being called global arguments, it actually did 3 things:

  1. copy global configuration directly
self.mean_scatter_times_list = args.mean_scatter_times_list
self.n_jobs = args.n_jobs
self.T_total = args.T_total
self.output_path = args.output_path
self.null_model = args.null_model_i
  1. Process global configuration, then saved into self for easier internal use
self.checked_epicenter = [x for x in args.epicenter_list.split(",")][0] if isinstance(args.epicenter_list, str) else args.epicenter_list[0]
  1. Initialize empty containers for future results
self.y = None
self.r_dict = {"simulation":{self.checked_epicenter: {"combinations":[],"max_r_each_run":[-1000], "max":[], 'max_indices':[]}},
                       "Rmis":{self.checked_epicenter: {"combinations":[],"max_r_each_run":[-1000], "max":[], 'max_indices':[]}}}

My Usage

My current code is still mostly procedural, so I only applied the simpler part of this design: using input arguments to decide output organization and workflow conditions:

def main() -> None:
    args = parse_args()

    input_dir = args.input_dir.expanduser().resolve()
    output_dir = input_dir / "plots"  # i didn't pass output_dir to args
    output_dir.mkdir(parents=True, exist_ok=True
    ...
    if args.draw_residual:
        data_regions = (dat_pred[value_col] - dat_pred[observation_col]).to_numpy()
    else:
        data_regions = dat_pred[value_col].to_numpy()

Current limitations:

  • most of my operations mainly in main() , not become the inter-script pass.
  • although i use args.input_dir to generate output_dir, i didn’t save it back to the args.
  • I only used args.draw_residual as a most simple condition, exist or not. exist means i want to draw residual

Possible improvements:

  • save derived paths back into args
  • use metadata to drive plotting decisions, not CLI
  • organize outputs based on experiment settings

Takeaways

  • what can you do with all information might be helpful?

    👉 Path → Variable → Conditions→ Output organization

  • Before write script, you have to think about how to arrange your model information, which variable is most important that it needs to be on the “model_name”

  • A well-designed output path can store experiment metadata.

  • Procedural projects may still use OOP when some part of the workflow needs long-lived state.

  • A class can copy, normalize, and store only the configuration it needs.
